# CopyInsert

A LibreOffice extension that [short description of what it does].

## Documentation

This LibreOffice extension enables Copy/Insert, Copy and paste special/Insert, Move/Insert and Cut/Insert capabilities for Rows, Columns, and Cells in Calc documents/spreadsheets. These functionalities are available after selecting the source data (either row(s), column(s), or cell(s)) and using either the Edit menu or the mouse right-click button.

Full documentation is available on the CopyInsert wiki page: [https://wiki.documentfoundation.org/User:CopyInsertExtension]
