# CopyInsert
A LibreOffice extension that enables Copy/Insert, Copy and paste special/Insert, Move/Insert and Cut/Insert capabilities for Sheets, Rows, Columns, and Cells in Calc documents/spreadsheets. These functionalities are available after selecting the source data (either row(s), column(s), or cell(s)) and using either the Edit menu or the mouse right-click button. Destination must not be on protected sheets.
